# Currency Converter

A real-time currency conversion web application that fetches accurate, global exchange rates using an external financial API. 

## 🚀 Features
* **Live Exchange Rates:** Uses asynchronous JavaScript (`async/await`) to fetch dynamic financial data from the Vatcomply Rates API.
* **Dynamic Flag Updates:** Automatically changes country flag icons in real-time when a new currency is selected from the dropdown via the FlagsAPI.
* **Smart Input Validation:** Sanitizes the amount input box automatically, defaulting to a base value of 1 if left empty or given a negative number.
* **Complete Global Dictionary:** Maps a comprehensive custom country-to-currency code object to easily switch between dozens of global currencies.

## 🛠 Tech Stack
* **JavaScript (ES6+)** - Handles asynchronous API data fetching, user input checks, dynamic DOM manipulation, and mathematical math calculations.
* **HTML5** - Defines form inputs, currency selection options, layout containers, and image nodes.
* **CSS3** - Centers components using Flexbox layouts, styles custom form elements, and controls sizing constraints.
